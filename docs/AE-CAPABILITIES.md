# After Effects 创作能力对照

目标：自有工程格式、外部 agent 可编程创作与功能对标。这里记录真实状态，不以 SDK 接口预留作为完成标准。

本轮已重构工作站和八类可视化面板：节点连线、动画层/动作、属性表达式/布局/路径、三维、粒子、分镜/混音、原生检查与性能。下表曾列为剩余的“交互节点画布、动画层面板、表达式控制器”已有首版，复杂参数/拓扑/绑定等仍待深化。详见VISUAL-WORKSTATION.md。

当前十八个内置模块137项能力，默认MCP十入口；所有内置工具已统一分发。节点图多输入/命名输出/ROI分块、代理自动预览、动画叠加层/外插、序列混音/侧链/响度取证、项目引用索引及原生颜色/候选差分/图层影响已实现，下面“剩余”不再把这些基础重复列入。

GPU首批实现Direct3D12颜色矩阵/keyer/单输入通道融合，提供二进制帧、有界复用与CPU精度/性能对照。以下剩余GPU指全场景/3D/其它效果及共享纹理，并不否定这批局部加速，详见GPU-EFFECTS.md。
