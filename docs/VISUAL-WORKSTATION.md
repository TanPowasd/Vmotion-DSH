# 可视化工作站

顶部项目操作、工作区切换、保存状态和导出集中在独立工作站栏。左侧工程/素材、中心画布、右侧检查器、底部时间轴继续可调大小，图层拖拽、多选和独立合成保持原行为。“创作工具”在中心打开专用编辑区，保留选区与时间轴；工具和属性驱动按需加载，隐藏画布暂停预览请求。界面默认简体中文，技术术语和稳定 ID 保留。

| 入口 | 可视化操作 |
|---|---|
| 特效节点 | 添加/拖动节点、端口连接、分支输入、输出选择、颜色矩阵、抠像、通道路由/常量、纹理、基础效果参数；现有资源带 hash 更新 |
| 动作编排 | 五种动作模板、多对象错峰、权重/混合/外插；动画层新增/复制/排序/开关，局部时间/曲线/关键帧编辑 |
| 三维场景 | 六种模型和 OBJ 创建、相机/投影、TRS、材质/金属度/粗糙度/自发光、方向光/已有点光、环境光/曝光；支持生成图层覆盖 |
| 粒子 | 发射模式/形状/中心/范围、数量/速率/种子、速度/寿命/尺寸、重力/阻力、颜色与发光，确定性位置示意与真实候选画面 |
| 分镜与转场 | 镜头卡片拖动/排序、章节、来源/入点/时长/配音，保存到轨道；八种场景转场。新分镜默认独立轨道，已有内容重叠不会被悄悄覆盖 |
| 混音 | 轨道/总线/主输出、增益/声像、路由/发送/独奏、侧链、EQ/处理链、归一化与草稿试听 |
| 画面检查 | 原生 SDR 示波器、图层隐藏影响、候选差分/重复稳定性、采样时间/尺寸/透明度统计、图片与短指标 |
| 渲染性能 | CPU/auto/GPU 测量和 CPU 对照、耗时/像素容差、设备/缓冲/回退/修正；导出对话框可选后端并固定版本 |
| 检查器 | 创建/删除表达式、布局锚点/比例尺寸、SVG 路径/进度/朝向/重复；普通关键帧外插。既有文字、矢量、遮罩、效果栈、主题/模板、内容时间和跟踪继续保留 |
| 原工作区 | 多轨剪辑/字幕/波形、笔迹/画稿发布再编辑、乐曲音符、代码编辑/检查、媒体/代理/缓存、插件管理继续可视化操作 |

编辑工具保存草稿的基准版本。点击“预览修改”生成固定候选，再用共享预检渲染真实画面；通过后“应用修改”提交同一候选、一次撤销。编辑草稿会使旧预览失效；工程被其它窗口/agent 修改后不能提交旧候选。“重置草稿”明确丢弃当前面板草稿并读取当前工程，关闭并重新打开也会读取当前状态。采样检查不能证明整个作品正确。

`composition_edit_layers` 新增 `mode:"plan"`（默认仍为 `apply`），返回与其它工具相同的存储候选。UI 的生成 3D 编辑不改 TypeScript 源码，也不复制另一个编辑行为。相机/材质修改保留原动画通道，对修改的已动画数值在当前局部帧写键；大网格资源仍通过引用保留。图节点位置是界面中的临时布局，不写成效果参数。复杂参数声明/子图资源创建、曲线拓扑、完整 DAW/曝光表和模型绑定仍需代码或后续专用界面；本轮不宣称所有接口都已有可视化面板。

在同一个真实 Electron 窗口检查现有工作流与新工具的候选、保存、图像和版本保护，截图/测试工程写入忽略的 artifacts。

解码改为少量预读取、保留原始时间戳并沿固定 FPS 网格取样。
