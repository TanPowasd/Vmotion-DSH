# 创作工作站界面

桌面版启动进入项目首页，不自动打开演示视频。首页提供新建、打开和最多 12 个最近项目；最近列表仅保存于用户数据，缺失文件夹明确标记。新建默认为空白工程，也可选择科普波形模板，并设置项目名称、保存位置、画布尺寸、帧率和初始时长。29.97/59.94 使用有理数时间基准，时长换算到整数视频帧。

编辑器顶部提供首页、新建和打开按钮；Ctrl+N 新建，Ctrl+O 打开。点击工程名称进入设置。打开时选择含 project.vmotion.json 的工程文件夹；命令行 `--project` 也接受清单路径。打开失败保留当前工程，创建时拒绝非空文件夹，Windows 保留字符/名称不会被用作项目目录。

当前工作区分为工程总览与独立合成。工程总览的时间轴组织场景/视频/音频；点击场景进入独立合成后，时间轴只显示该场景的图层。图层组与代码组件可以双击，或通过图层右侧箭头/属性面板“进入独立合成”继续进入。面包屑与浏览器返回可逐级退出。

- 普通组修改其原始图层数据；代码生成图层修改保存为稳定 ID 的 `overrides`，支持撤销，不反向改写 TypeScript。
- 组隔离后移除组外内容，并以组内坐标显示；组件使用自己的画布尺寸。父级应用的变换/效果在返回外层后参与最终合成。
- 图层列表与场景时间轴只显示当前合成的直接子图层，避免同时堆叠所有内部层级。
- 工程、属性面板和时间轴支持拖动分隔线；界面布局仅保存在当前浏览器本地，不写入工程源码。
- 画布支持适应、缩放、Alt/中键平移、安全框和透明网格。
- 画布支持一次按下并拖动移动图层，无需双击；可以直接选中代码组件/嵌套组内可见的文字，属性修改仍保存到原图层或组件的稳定 ID 覆盖。
- 采用 AE 风格的选择工具：普通点击其他对象切换选择，直接拖动移动；Ctrl 单击添加/取消多选，拖动任意已选对象一起移动。空白处拖框选择，Ctrl 拖框追加选择；点击空白处清空选择。图层列表与时间轴也支持 Ctrl 多选。
- 多选移动是一次原子事务和一次撤销操作，不会丢失同一个组件上的其他覆盖。不同父级分别换算位移；父子同时选中时避免位移重复叠加。
- 拖动中通过同一原生核心显示临时画面，松开后产生一次保存/撤销操作；单纯点击不写工程。Shift 约束水平/垂直移动，Esc 或指针取消撤销未提交的拖动。
- 拖动与外部修改：拖动提交时若工程刚被外部保存/热重载改变（服务端返回 `REVISION_CONFLICT`，旧版显示“Project changed before composition editing”并丢失拖动），编辑器会重新读取一次状态；被拖动图层的节点数据和画布矩阵都没变时，在新版本上原样重发这次拖动；有变化时放弃这次拖动，在状态栏提示“项目文件刚在外部修改…请重新拖动”，并显示刷新后的工程。只重试一次。外部保存发生在拖动过程中时，画布交互层保持挂载直到松开，拖动不会被静默取消。
- 拖动位移通过父级与相机变换换算，支持嵌套旋转、缩放及画布缩放/平移。已有位置动画的图层在当前帧更新关键帧。
- 文本命中范围使用原生文字排版；绘画图层按笔迹命中，避免整张绘画画布遮挡下方文字。
- 素材库单击选择素材，拖入画布按落点放置，双击也可添加。画稿资源创建绘画图层，不送入图片解码器。
- 时间轴支持缩放、定位、边界吸附、片段拖动/裁切和图层时段调整；场景与序列拥有各自的播放位置。
- 剪辑/工程总览支持分段声音试听、监听音量/静音和实时电平，播放头跟随音频时钟。独立合成采用静音画面预览，详细范围与 agent 接口见 [AUDIO.md](AUDIO.md)。
- 检查器分为属性、效果、动画页签；效果可排序，动画页可编辑曲线。
- 时间轴关键帧支持 Ctrl 多选、整组拖动、复制粘贴及独立删除；动画页支持批量时间/缓动操作、帧号/数值输入和贝塞尔控制点。完整命令与碰撞规则见 [KEYFRAMES.md](KEYFRAMES.md)。
- 组件参数显示枚举、布尔、向量、数组与嵌套对象；数组分页编辑、插入/移除/排序同步保留项目动画，◇ 可一次建立默认参数的数字叶节点关键帧。
- 图层组的选择框由当前帧可见子图层计算，包含路径几何、嵌套变换与笔迹范围，不使用默认原点方框。
- 「检查画面」跨开头/当前帧附近/中间/末帧检查文字排版与运动，输出标注图及对象时间定位。几何提示需要目视确认，规则、筛选和预算见 [VISUAL-AUDIT.md](VISUAL-AUDIT.md)。
- 代码工作区的行号与源码同步滚动；滚轮、键盘定位和水平滚动都保持逻辑行对应，源码不自动折行。
- 代码工作区可「预检代码」：类型/运行错误显示文件、行、列并可点击定位；通过后显示开头、当前、中间与末帧的候选画面。预检不保存工程，保存组件使用相同检查与原文件 hash，避免覆盖并发修改。
- 独立合成有可刷新链接，支持浏览器返回；工程总览、每个场景和每个内部组各自保留播放位置。

图层工具栏支持编组、复制、删除与上/下排序。Ctrl+G 编组，Ctrl+Shift+G 解组，Ctrl+D 复制，Delete 删除全部选中图层。生成内容的结构编辑写入所属组件的 `structure`，不改写源码；进入组内后仍可添加图层，新增图层也支持属性覆盖与动画。编组要求同一父级；有组级变换/动画/效果的组暂不允许解组，以免破坏画面。

绘画改为独立图层文档：先绘画，再发布整张画稿或选定图层到素材库，随后拖入场景/主时间轴。素材库显示绘画缩略图，详情与 agent 示例见 [DRAWING.md](DRAWING.md)。操作历史使用有界压缩快照和原子保存，重启可恢复撤销与重做；无变化的操作不会清空重做历史。
